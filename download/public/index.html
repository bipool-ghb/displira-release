Fire TV Installation

  1. Install or open Downloader on your Fire TV.
  2. Allow Downloader to install unknown apps if prompted.
  3. Enter: download.displira.com/displira.apk
  4. Download and install Displira Player.
  5. Launch the app.
  6. A pairing code will appear on screen.
  7. Pair the device from admin.displira.com.
